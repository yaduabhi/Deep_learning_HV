# Deep Learning Course Assignments

This repository contains assignments for the Deep Learning course. Each assignment covers fundamental concepts in deep learning with hands-on implementation exercises.

## Prerequisites

- Python 3.8+
- NumPy
- Matplotlib
- TensorFlow 2.x or PyTorch (for Assignments 2 and 3)

## Installation

```bash
pip install numpy matplotlib tensorflow
# or
pip install numpy matplotlib torch torchvision
```

## Assignments

### Assignment 1: Introduction to Neural Networks
**Location:** `assignments/assignment_1_intro_to_neural_networks/`

Topics covered:
- Understanding basic neural network structure
- Implementing the sigmoid activation function and its derivative
- Building a simple perceptron from scratch
- Creating a multi-layer neural network using NumPy
- Training on the XOR problem to understand non-linear classification

### Assignment 2: Convolutional Neural Networks (CNNs)
**Location:** `assignments/assignment_2_convolutional_neural_networks/`

Topics covered:
- Understanding convolution operations
- Implementing 2D convolution from scratch
- Max pooling operations
- Building a CNN for image classification (MNIST)
- Visualizing learned filters and feature maps

### Assignment 3: Recurrent Neural Networks (RNNs)
**Location:** `assignments/assignment_3_recurrent_neural_networks/`

Topics covered:
- Understanding RNN architecture
- Implementing a basic RNN cell from scratch
- LSTM and GRU architectures
- Sequence prediction with LSTMs
- Character-level text generation (bonus)

## How to Use

1. Clone this repository
2. Navigate to the assignment directory
3. Open the Jupyter notebook (`.ipynb` file)
4. Follow the instructions and complete the TODO sections
5. Answer the conceptual questions at the end

## Submission Guidelines

For each assignment, please submit:
1. The completed Jupyter notebook with all code implemented
2. Answers to all theoretical questions
3. Any required visualizations and plots
